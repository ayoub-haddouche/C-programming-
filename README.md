# Personal Expense Tracker System in C

A CLI application written in C to manage daily personal expenses using file processing.

## Features
- Add, search, modify, and delete expenses.
- Binary file storage (`expenses.dat`).
- Activity logging with dates and timestamps (`activity.log`).
- Input validation for IDs and financial amounts.

## How to Run
1. Compile the code:
   ```bash
   gcc main.c -o expense_tracker
2. Run the code: 
  ```bash
   ./expense_tracker
